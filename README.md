# vmp3-demo-devirt

A devirtualizer for the code virtualizer in the VMProtect 3 demo, which is very similar to the one in VMProtect 2.

> [!WARNING]
> This project is incomplete, and its methodology is not a good one to follow. See the "Warning To The Wise" section of [this blog post](https://aftermathlabs.net/blog/09/05/2026/).

Developed from January to June 2025. Inspired by [aftermathlabs/vmp2](https://github.com/aftermathlabs/vmp2).
For educational purposes only.
